# Entrega 2: contratos y documentos (puntos 9, 10, 11, 12, 13, 16, 17, 21)

Aplicación de los ocho puntos definidos, sin alterar el proyecto Huella original ni la instalación local.

9. Contrato indefinido activo sin fecha de término, preservando cualquier valor histórico anterior.
10. Se diferencia el nuevo sueldo base del importe del aumento y se muestra una vista previa.
11. La aprobación explícita, por administración o supervisión, de un anexo con PDF firmado aplica el sueldo una sola vez. El registro del anexo o del PDF por sí solo no lo aplica. La base y el historial quedan auditados.
12. La sucursal se propone como lugar habitual, sin reemplazar un valor anterior automáticamente.
13. Campos AFP, Fonasa, Isapre y nombre de Isapre. Se conserva healthSystem para registros anteriores.
16. Fecha de inicio sigue la de entrega hasta que el usuario la modifica directamente.
17. Guardar y validar cierran la ficha cuando todas las secciones se guardaron correctamente.
21. Se protege contra pérdidas de borradores generales, médicos, contractuales y de documentos.

Seguridad: migración aditiva, fila única por anexo aprobado, auditoría y orden cronológico; ningún recalculo de liquidaciones, cotizaciones o retroactivos. Se requieren pruebas automáticas y posteriormente validaciones físicas en Windows y móvil.
